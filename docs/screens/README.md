# README screenshot notes

Captured 31 October 2026 from the current Android interface on the local Android TV preview emulator. Source baseline: `9ac15c0`. Images are 1920 × 1080 JPEGs displayed at full article width in the main README.

- The launcher uses the current release build. The Feed and Ambient News preview builds use the same rendering code, with fixtures loaded into emulator storage; no screenshot-only rendering changes are included in the project.
- Public TMDB title artwork and representative catalogue entries illustrate the layout. They are not a claim about today's new releases, ratings or streaming availability. App banners are preview stand-ins; installed streaming apps can supply different banners.
- Continue-watching progress and episode labels are samples, not a user's viewing history.
- Portfolio values, daily changes and market quotes are fictional. The total portfolio is a round ₹10 lakh example; it is not the owner's balance. No financial account was connected to this preview.
- `ambient-news.jpg` was captured on the physical BRAVIA (31 October 2026) during Google Ambient: a real Google News story, the publisher's photo, and a QR code to the article.
- In `header.jpg` the drawer tiles show the apps' own TV banners (from the installed apps and the BRAVIA's Home), in place of the preview stand-ins.
- Settings captures show the actual switches, with no API keys or provider credentials displayed. Emulator clock dates are preview state.
- Captures were inspected before JPEG conversion and publication. Raw captures, device connection details, fixture JSON, preview apps, keys and tokens are not part of the documentation change.
